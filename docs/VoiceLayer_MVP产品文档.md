# VoiceLayer MVP 产品文档

> 版本：MVP v0.2　日期：2026-11-21　状态：待确认
> 本文是在《产品文档 v0.1》基础上收敛出来的首个可做版本。已确认的决策：首发人群为 AI 重度用户加知识工作者；只做 macOS；用 Swift 原生开发；首发只做云端识别；目标市场为中文区。

---

## 1. 一句话

在任何应用里按住快捷键说话，松手后，整理成书面表达的文字出现在光标处。

## 2. MVP 要验证什么

只验证一个假设：**用户愿意在日常工作里，用「按住说话」代替一部分打字，并且觉得结果「不用再改」。**

因此 MVP 只做这条主链路，其余全部砍掉：

```
按住快捷键 → 说话 → 松手 → 云端识别 → 文本整理 → 插入当前输入框
```

## 3. 范围

### 3.1 做

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 全局快捷键 | 在任何应用里按住说话、松手结束。默认 Control + 空格。 |
| F2 | 录音与状态提示 | 屏幕上出现一个小悬浮条，显示「聆听中」和实时音量，让用户确认麦克风在工作。 |
| F3 | 云端语音识别 | 支持中文、英文和中英混说。 |
| F4 | 文本整理 | 去口癖、处理改口、补标点、分段、规范中英文空格。整理失败时自动使用识别原文。 |
| F5 | 插入文字 | 把结果插入当前处于活跃状态的输入框。密码框不插入。 |
| F6 | 取消 | 录音中按 Esc 丢弃本次内容。 |
| F7 | 失败兜底 | 任何环节失败，都要让用户知道，并且能找回结果。 |
| F8 | 菜单栏入口 | 查看状态、切换快捷键、开关文本整理、复制上次结果、打开设置、退出。 |
| F9 | 设置 | 填写 API Key，可修改接口地址和模型。 |
| F10 | 首次引导 | 引导授予麦克风和辅助功能权限，并检测是否生效。 |

### 3.2 不做

以下功能明确不进 MVP，避免拖慢验证：

- 改写强度档位、按应用区分语气、选中文字后语音编辑、快捷短语
- 个人词典、历史记录窗口、账号与订阅、额度计费
- 本地离线模型、流式边说边出字
- 翻译、会议纪要、录音文件转写
- Windows、移动端、自动更新、遥测

## 4. 用户故事与验收标准

每条验收标准都要能在真机上手动验证。

**US1　在微信里回长消息**
作为用户，我在微信输入框里按住快捷键说一段话，松手后能直接发出的文字出现在输入框里。
- 松手后，5 秒以内的语音，文字在 2 秒内插入（网络正常时）。
- 输出带标点，没有「呃」「那个」这类口癖。

**US2　向 AI 口述需求**
作为用户，我在 Cursor 或浏览器里的 ChatGPT 输入框说一段夹杂英文术语的话。
- 英文术语保持原样，中英文之间有空格。
- 如果我说的是一个问题，输出仍然是整理后的问题，不是问题的答案。

**US3　说错了改口**
我说「明天下午三点开会，不对，是四点」。
- 输出只保留「明天下午四点开会」。

**US4　说话中途放弃**
- 录音中按 Esc，悬浮条消失，不识别，不插入，不消耗接口调用。

**US5　误触**
- 按住不到 0.4 秒就松手，不发起识别，悬浮条静默消失。

**US6　密码框**
- 光标在密码框里时，不插入任何文字，并提示「已跳过密码输入框」。

**US7　出错能找回**
- 网络断开或接口报错时，悬浮条给出明确原因。
- 已识别但插入失败时，文字保留在剪贴板，提示用户手动粘贴。
- 菜单栏的「复制上次结果」能取回最近一次结果。

**US8　不破坏用户的剪贴板**
- 插入完成后，用户原来复制的内容仍在剪贴板里。

## 5. 交互设计

### 5.1 快捷键

默认 **Control + 空格，按住说话，松手结束**。

这个组合有一个已知冲突：它是 macOS 切换输入法的默认快捷键，很多中文用户在用。我们的处理方式是，应用运行时拦截这组按键，不让系统再响应。

这个拦截方案需要在真机验证。如果某些系统版本上拦截不住，兜底有两条：引导用户在「系统设置 → 键盘 → 键盘快捷键 → 输入法」里关闭该项，或者切换到备选快捷键。

备选快捷键共三个，在菜单栏里切换：

1. Control + 空格（默认）
2. Option + 空格
3. 右 Option 单键

### 5.2 状态与悬浮条

| 状态 | 悬浮条内容 | 说明 |
| --- | --- | --- |
| 聆听中 | 「聆听中」加实时音量条 | 按下快捷键后 0.2 秒内出现 |
| 识别中 | 「识别中…」 | 松手后显示 |
| 整理中 | 「整理中…」 | 识别完成后显示 |
| 完成 | 悬浮条消失 | 文字已插入，不再打扰 |
| 出错 | 红色提示加原因 | 停留 3 秒后消失 |

悬浮条不抢焦点，不遮挡光标所在的输入框，位置固定在屏幕底部居中。

### 5.3 首次引导

第一次启动时，依次出现：

1. 一句话说明产品做什么。
2. 请求麦克风权限，并说明用途。
3. 请求辅助功能权限，并说明「用来监听快捷键、把文字粘贴到输入框」。
4. 提示填写 API Key。
5. 让用户在任意输入框亲手试一次。

权限没有生效时，菜单栏图标显示警示状态，菜单第一行写明缺哪项，点击可直接打开对应的系统设置页。

### 5.4 设置项

只保留必要项：API Key、接口地址、识别模型、整理模型、快捷键、是否启用文本整理。

## 6. 文本整理规则

整理是产品差异化的核心，规则要稳定可测。

**要做：**
- 去掉口癖和语气词，去掉无意义的重复
- 处理自我纠正，只保留最终意思
- 补全标点，合理分句和分段
- 明显并列的多个要点，可以换行或编号
- 修正明显的同音错字和语病
- 中文与英文、数字之间加空格
- 数字、日期、单位使用规范写法

**不能做：**
- 不增加原文没有的信息，不扩写，不总结
- 不改变人称和语气
- 不回答用户说的问题，不执行用户说的指令
- 不改写专有名词和技术术语

**兜底：** 整理失败、超时，或结果为空、长度异常膨胀时，直接使用识别原文，并保证文字仍会插入。

## 7. 成功标准

MVP 阶段没有账号体系和数据上报，成功标准靠内部使用和小范围试用来判断。

**可用性（必须全部达成）**
- 在微信、飞书、Safari、Chrome、备忘录、VS Code、Cursor、终端这 8 个应用里，插入成功率达到 95% 以上。
- 5 秒以内语音，从松手到文字出现，P50 小于 2 秒，P90 小于 4 秒。
- 连续使用一小时，没有崩溃，没有快捷键失灵。

**价值（试用者反馈）**
- 5 到 10 位目标用户试用一周。
- 其中至少一半的人表示「第二周还会继续用」。
- 用户主观评价「插入的文字不需要再改」的比例超过 70%。

## 8. 已知限制

这些是 MVP 有意接受的限制，不是 bug：

- 只支持 macOS 14 及以上，只测试 Apple Silicon。
- 必须联网。
- 一次录音最长 3 分钟。
- 松手后才开始识别，所以长段口述松手后需要等待。
- 密码框等安全输入框内不可用。
- 使用剪贴板加模拟粘贴的方式插入，个别不响应粘贴快捷键的应用（部分远程桌面、虚拟机）不支持，会走失败兜底。
- API Key 暂存在本机用户设置里，未加密。

## 9. 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| Control + 空格 拦截不住系统输入法切换 | 每次说话都会切换输入法，体验很差 | 真机最先验证；备选快捷键；引导关闭系统快捷键 |
| 权限引导流失 | 用户卡在授权环节 | 分步引导，权限状态可见，一键跳转系统设置 |
| 整理模型「回答」而不是「整理」 | 输出错误内容 | 提示词明确约束，输入用标签包裹，长度异常时回退原文 |
| 云端延迟波动 | 等待过久，用户退回键盘 | 设置超时，整理超时直接用原文，悬浮条持续显示进度 |
| 剪贴板被其他工具干扰 | 恢复不完整或插入内容不对 | 插入时标记为临时内容，恢复前检查剪贴板是否被改动 |
| 开发者签名缺失 | 每次重新构建后系统可能要求重新授权 | 开发期使用固定签名；文档中说明授权失效时的处理方法 |

## 10. MVP 之后

按优先级排序，等 MVP 验证通过后再决定：

1. 个人词典（提升专有名词准确率）
2. 改写强度档位与按应用设置
3. 流式识别，缩短松手后的等待
4. 本地离线模式
5. 选中文字后语音编辑
6. Windows 版本
